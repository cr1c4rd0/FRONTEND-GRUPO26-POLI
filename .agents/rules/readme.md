# Reglas de Documentación y README

- **Prohibido agregar la sección de "Documentación e Informes Académicos (`docs/`)" al archivo `README.md`**:
  - No incluir encabezados ni tablas de informes académicos para `docs/`.
  - No incluir `docs/` en la tabla de contenidos (índice) ni en el árbol visual de directorios del `README.md`.
  - La carpeta `docs/` se mantiene estrictamente excluida vía `.gitignore` y no debe exponerse ni documentarse en el repositorio público ni en el README.
